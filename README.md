# 밤비네 연구소 (Bambi Lab)

Google Sites(`sites.google.com/janggoons.kr/bambilab`)에서 옮겨 온 Jekyll 기반 GitHub Pages 사이트입니다.

- 각 페이지: 폴더별 `index.md` (마크다운 + 이미지)
- 메뉴: `_data/nav.yml`
- 레이아웃/스타일: `_layouts/`, `_includes/`, `assets/css/style.css`
- 이미지: `assets/img/`
- 프로젝트 저장소(`/bambilab`)가 아니라 사용자 사이트(`<계정>.github.io`)로 쓸 때는 `_config.yml`의 `baseurl`을 `""`로 변경
